# Data directory

Source and processed data for the *Scientific Data* Data Descriptor **"Recovered TED bidder counts
and full-bid-set eForms tenderers for European public procurement."** The published, citable dataset
(the files described in the descriptor) lives on Zenodo, not here — this directory holds the local
source and intermediate files the build scripts read.

- **Deposit (data + code):** Zenodo concept DOI **[10.5281/zenodo.19456216](https://doi.org/10.5281/zenodo.19456216)**
  (always resolves to the latest version). Data CC-BY 4.0; code MIT.
- **Descriptor:** [`../Scientific_Data_Descriptor/`](../Scientific_Data_Descriptor/)
  (`descriptor.tex`, Supplementary Information, `CLAIMS_INDEX.md`, `DEPOSIT_README.md`).

Large files here are gitignored and are regenerated by the pipeline or downloaded from Zenodo.

## Directory structure

```
Data/
├── processed/            # harmonised / intermediate parquet (gitignored; large)
│   └── eu_ted/yearly/    # per-year TED contract-award-notice (CAN) parquet — input to the rebuild
├── raw/                  # raw source data (EU-ETS/E-PRTR, Eurostat, EXIOBASE, etc.)
└── reference/            # small reference tables (CPV→sector crosswalks, etc.)
```

## How the deposited contract file is built

The flagship deposited file, `procurement_awards_2012_2023.parquet` (16.97M de-duplicated,
carbon-mapped contracts across 33 territories), is rebuilt from the raw TED CAN files by
[`../scripts/descriptor/build_contract_file.py`](../scripts/descriptor/build_contract_file.py):
it unions the yearly CAN parquets in `processed/eu_ted/yearly/`, de-duplicates on
`notice_id × award_id`, dates each award by dispatch date, attaches the CPV→EXIOBASE carbon weight,
and merges the flagged non-TED sources (Colombia SECOP, UK Contracts Finder). See the descriptor's
Methods and `DEPOSIT_README.md` for the full data dictionary and provenance.

## Data sources

| Source | Coverage | `source` flag | URL |
|--------|----------|---------------|-----|
| EU TED | 31 TED-reporting countries, 8.18M awards | `TED` | ted.europa.eu |
| Colombia SECOP | Colombia, 7.97M | `SECOP` | datos.gov.co |
| UK Contracts Finder | United Kingdom, 0.82M | `ContractsFinder` | gov.uk/contracts-finder |
| EXIOBASE 3.8.2 | sector carbon intensities | — | [10.5281/zenodo.5589597](https://doi.org/10.5281/zenodo.5589597) |
| Eurostat air emission accounts | carbon-weight validation | — | ec.europa.eu/eurostat |
| EU-ETS (EUTL) / E-PRTR | firm-emissions crosswalk | — | eea.europa.eu |

Bidder counts are a TED measure only; SECOP records carry an administrative competitive-vs-direct
indicator (≈98.4% report 0/null offers) and must be excluded from bidder-count analysis
(`source == "TED"`).
